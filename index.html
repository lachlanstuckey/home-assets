One-time setup

Paste your Google OAuth Client ID and Spreadsheet ID to connect the app to your private Google Sheet.

Setup guide:
1. Go to console.cloud.google.com
2. Create project → Enable Google Sheets API
3. Credentials → Create OAuth Client ID → Web application
4. Add your hosted URL to Authorised origins
5. Copy the Client ID above
6. Create a Google Sheet, copy the ID from the URL
7. Share the sheet with allowed Google accounts only
